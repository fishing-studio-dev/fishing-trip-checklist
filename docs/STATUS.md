## 起動方法

```
cd game
npm start            # http://localhost:8080/ を開く（Node 18以上、追加インストール不要）
# または: python3 -m http.server 8080 -d game
```

- ES Modules を使うため、`index.html` をファイルとして直接開く（file://）と動かない。必ずローカルサーバ経由で開く。
- `?dev=1` を付けると開発モード（海図に魚群を「開発表示」付きで表示、テスト用API）。通常プレイでは使わない。
- 探す道具の効果：`node tools/searchbot.mjs 10,11 77`（同じ測線を道具ごとに走り、見つけた根・漁礁・群れを数える。1日あたり約2分）。
- 描画の重さの目安：`node tools/perf.cjs`（ヘッドレスChromiumで、海での毎秒のコマ数と処理時間）。
- 漁法ごとの稼ぎの目安：`node tools/econone.mjs handline 10,11,12 1`（魚の位置を知っている自動の漁師で1日ずつ。1日あたり約1〜2分）。
- 検証：`npm test`（コア160件）、`npm run e2e`（ブラウザ通し試遊101項目、約13分）、`npm run lint`。

### 基本の流れ

1. **港**：「今日の海図」で次の4つを1画面で確認し、「A/B/Cを狙って出港」か「狙いを決めずに出港」を選ぶ。
   - 候補A〜C（根拠・情報の新しさ・自分の実績・装備で可能か）
   - 仲間の話（観測した時刻と聞いた時刻を区別）
   - 予報
   - 自分の腕前・装備
2. **海**：海図と魚探で確かめて場所を決める。
   - 一本釣り：群れの潮上で停船し、Spaceで開始。投入・タナ・合わせ・回収は自動。
   - 曳縄：航路を決めてSpace。航行と仕掛けの作業は自動で、航路はいつでも変更できる。
   - 延縄：張る向きを決めてSpace。縄（針100本・約600m）を海底に張ったら、浸けている間は自由に動ける（他の漁もできる）。L で揚げる。
   - 朝のうちに仲間から無線が入る。
3. **帰港**（H）：着岸すると自動で一括水揚げ・精算・保存する。漁法ごとの経験、狙いと結果、無線で聞いた話が記録される。
4. **翌朝の港**：新しい仲間の話と、自分の日誌を踏まえた候補が出る。

## 実装済みの範囲

### M0
- 架空の海域（3km四方）、水深、潮流、風、水温。
- 下向き魚探：時間履歴で表示し、パネルを閉じても記録は続く。
- 3D表示（three.js）：簡易モデル、操船視点と作業視点の切替。
- 一本釣りの自動操業（胴突き3本針）。漁獲は「候補・処理能力・群れの残量・魚倉の残り」の最小で決まる。
- 漁法レベル、電動リール、帰港時の自動精算。
- 保存：版付き・バックアップ・読めないデータの退避・書き出し／読み込み。

### M1
- **日をまたいで続く海**
  - マアジは漁場に数日〜1週間ほど居着き、去る前は群れが薄くなる。
  - サワラは水温が高い時期に、波状に回遊してくる（全体の約2割の日）。
  - 水温は日ごとに滑らかに変化する。
  - 予報（風・水温）には誤差があり、海で出会う実際の状態とは別物。
- **序盤の筋書き（0〜6日目）**：引き継ぎ書§7.5の3シナリオが起きるよう、海の状態を設定した。報告は通常の日と同じ仕組みで、その海から作られる。
  - 1日目：仲間の新しい情報で、初めての場所（北の瀬）へ行く。
  - 2日目：前日と似た条件で、自分の実績を再現する。
  - 3〜5日目：サワラが来て曳縄の候補が出る。5日目は大潮・強風で、北の瀬の食いが落ちたという報告があり、切り替えの判断になる。
- **漁師仲間2人**（源さん：一本釣り、浜田さん：曳縄）
  - 報告は、観測した時点の世界の状態から作る。
  - 種類（水揚げ／反応なし／魚探反応／目撃／経験則）、観測時刻、聞いた時刻を区別する。
  - 見立て・予想は観測とは別欄に書く。
  - 又聞きは元の観測IDで判別し、独立した根拠として数えない。
  - 同じ人の同じ場所の古い結果は、新しい結果で置き換わる。
  - 港で朝に聞く話（自動で保存）と、海上の無線（6〜8時台）がある。
- **今日の海図と候補**
  - 候補（狙う魚×漁法×漁場）2〜3件を、根拠つきで示す。
  - 候補は、プレイヤーが聞いた話・自分の日誌・予報だけから作る（現在の魚群は参照しない）。
  - ラベル：今朝の確認情報あり／昨日の情報あり／自分の実績あり／似た条件の記録あり／情報が古い／反応なしの報告あり／情報が少ない／未経験／装備が必要。
  - 未経験は「情報不足」として表示し、不適合とは表示しない。
  - 装備が足りない候補は理由を示し、出港ボタンを押せないようにする。
- **狙いの記録**：選んだ候補の狙いと根拠を海上で表示し、操業日誌と帰港結果（狙いと結果）に残す。
- **曳縄（サワラ）**
  - 曳縄具TR-1（9,000G）を、船尾の取付位置（初期は空き）に付ける。
  - 航路は「今の向きで往復」か、海図で経由点（最大6）を指定する。
  - 自動航行は決めた航路を走るだけで、魚を探しに行かない。
  - 曳縄中は舵の入力を必要とせず、受け付けない。航路の変更と中止はいつでもできる。
  - レベル（手際）は投入・やり取り・手繰り・取り込みの速さに効く。
- **漁法ごとのレベルと経験**：経験はその漁法で獲った数と操業時間から入る。操業時間の分には上限がある。
- **日誌**：漁法と場所で絞り込み、今日の予報と似た条件の記録をまとめる。
  - 1回だけの好結果は「傾向とまでは言えない」と表示し、確率は出さない。
  - 装備やレベルが今と違う記録には印を付ける。
  - 聞いた話の記録（観測時刻と聞いた時刻）も見られる。
- **セーブ形式の版上げ（1→2）**：M0のセーブは自動で移行する。資金・経験・装備・日誌は保たれ、移行前の原本も別のキーに残す。

### M2（2026-11-23）
- **船の買い替え**（港の「船の買い替え」）

  - 漁法：根魚釣り・泳がせ釣り・イカ釣り・曳縄・延縄を初めて選んだときに、その漁法の1回だけのコツ（どこで止めるか、何が自動か）を出す。
  - 見たかどうかは、その端末のブラウザに `ryoshi-game:guide` として覚える（セーブとは別。読めないときは最初から）。シミュレーションには触れない。
  - 置き場所：PCは上の表示の下、スマホ縦は知らせの上、スマホ横は操作ボタン（と甲板を歩くときの持ち場バー）の上。海図モードの間は出さない。操作ボタンを覆わない。
- **10. 天候**（本作設定）：(seed, 日) の関数。序盤の筋書きの日（0〜6日目）は晴れ。

  - 霧（約16%）：朝7時半〜10時半ごろまで視界150〜400m。3Dが霧に包まれ、海面の手掛かりは視界の中しか見えない。海図・魚探・ソナーは使える。上部に「霧 視界 約○m」。

### M4「人手と季節」（2026-11-23）
- **甲板員（乗組員）**
  - 港で「今日は甲板員を乗せる（日当1,800G・帰港時に精算）」にチェックして出港すると、手が2人になる。資金が日当以上あるときだけ選べる。
  - 手の要る作業（餌付け・取り込み・手巻き・曳縄の出し入れ）が2つまで同時に進む。
  - 延縄では、甲板員が魚を外す間も揚げ続ける。
  - 腕前は自分と同じ扱い。1人でも漁はすべてできる（甲板員がいないと自動化できない、という仕組みにはしない）。
  - 日当は帰港時の精算で経費として1回だけ払う。海上で閉じた航海では払わない。
  - 日誌に「＋甲板員」と記録する。3Dでは橙色の上着の甲板員が、2つ目の作業の持ち場へ歩いて移る。
- **季節の移り変わり**（本作設定）
  - 水温の高さと、ここ2日の上がり下がりから季節を決める（水温の上がる時期／高い時期／下がる時期／低い時期／落ち着いた時期）。港の予報に「季節」として出る。
  - **マダイの乗っ込み**：水温が17.9〜19.3℃で上がっている時期は、マダイが北の瀬の裾に集まる。数が多く、大ダイが多い。その間、ほかの漁場のマダイは減る。
  - 松じいはこの時期に北の瀬の裾へ縄を入れ、経験則として話す。延縄の候補に「乗っ込みの頃」の注意が出る（予報からで、魚の位置からではない）。
  - 水温が18℃以下の日は、漁場に付くアジの群れが小さくなる（7日目以降）。

### M3の最初の区切り（2026-11-23）
- **延縄（マダイ）**：3つ目の漁法。
  - 判断：どこに、どの向きに縄を張るか（今の向きにまっすぐ、または海図で経由点を指定）と、いつ揚げるか。
  - 自動：投縄（張りながら進む）、揚げ縄（縄に沿って進みながら1本ずつ揚げる）、取り込み。
  - 釣果：針ごとに、置いた場所の海底のマダイの密度から、決まったゲーム時間ごとに当たりを計算する。場所に関係なく時間で魚が湧く方式ではない。餌は時間とともに弱まり、浸けすぎても増え方は小さくなる。
  - 浸けている間は船が自由になり、一本釣りや曳縄ができる。揚げ縄（L）はブイまで移動補助で向かってから揚げる。帰港（H）や日暮れのときは、縄を必ず先に揚げる（海に置き去りにしない）。
  - 腕前は投縄・揚げ縄・取り込みの速さに効き、同じ時間に多く浸けられる。
- **マダイ**（本作設定）：水深30〜60mの平場・駆け上がり・根の外側の底に薄く広く散り、何日も居着く。潮が動く時間と朝夕によく食う。価格は小ダイ700・マダイ1,000・大ダイ1,300 G/kg。
- **延縄具 LL-1**（12,000G、針100本・6m間隔）
  - 小型和船では船尾に付けるため、曳縄具とは付け替えになる（外した方は倉庫に入る）。
  - 中型漁船は「後部甲板（延縄）」の取付位置があり、曳縄具と両方を積める。
  - 船の買い替えでは、合う位置へ自動で移す。
- **3人目の仲間・松じい（延縄）**：7日目の朝から港の話と無線に加わる（序盤の筋書きの間は遠くの漁場に出ている設定）。延縄の結果（水揚げ／反応なし）と経験則（浸け時間・潮）を話す。報告は観測した時点の海から作る。
- **候補**：延縄（沖の平場・東の駆け上がり・西の根）が加わる。3つ目の漁法に新しい情報があれば4つ目の候補（D）として出す。
- **甲板を歩く**（視点切替 V の3つ目）
  - 釣り人を W/S で前後、A/D で向きを変えて動かす。
  - 持ち場のボタン（操舵席・右舷・左舷・船尾・揚げ縄機・魚倉）で、その場所へ移る。
  - 操業中は釣り人が持ち場で作業するので歩けない（見ることはできる）。
  - 歩いても海・船・漁獲は変わらない。表示だけで、シミュレーションには触れない。
- **釣り人と機械の動き**
  - 釣り人は作業のある場所へ歩いて移る。一本釣りは手の空く仕掛けへ、曳縄と投縄は船尾へ、揚げ縄は揚げ縄機へ。
  - 揚げ縄機は揚げている間回る。縄が船尾から出ていく様子と、揚げ縄機へ上がってくる様子も表示する。
  - 海にはブイ（旗付き）が浮く。
- **セーブ形式の版上げ（3→4）**：延縄の経験（0から）と、中型漁船の延縄の取付位置（空き）を追加した。M0〜M2のセーブは順に移行し、移行前の原本は別キーに残す。

## 残課題・既知の問題

- **バランスは仮設定**（価格・経験曲線・群れの規模・潮・当たり率）。
  - 自動試遊では、曳縄の日（サワラ12本・約1.6万G）が一本釣りの日（アジ約30尾・約8千G）のおよそ2倍だった。
  - サワラが来る日は限られ、装備費もかかるが、人による試遊で調整が要る。
- 曳縄のレベル差は、濃い群れを通るときにはっきり出る（Lv1 11本→Lv10 23本／30分）。薄い群れでは差が小さい（設計どおりだが、体感として要確認）。
- 3日目に浜田さんの早朝の「目撃」が出るかはシード次第（40シード中26）。4日目以降はどのシードでも曳縄の新しい情報が出る。
- 実機のスマホ（実GPU・実タッチ・Claudeアプリ内表示）での確認はまだ。ヘッドレスChromiumで4機種のタッチ操作とレイアウトを確認した（VALIDATION参照）。Safari（WebKit）エンジンは未確認。
- 日誌は最大500件、聞いた話は最大150件で、超えると古いものから削除される。
- M2の価格は仮設定。中型漁船は新艇110,000G・中古65,000G／85,000G、小型の下取り15,000G。通常のプレイで買えるまでの日数は未確認（一本釣りの日は約8千G、曳縄の日は約1.6万G）。
- 中古船の付属装備と自分の装備が同じ位置を取り合う場合、自分の装備は倉庫に入る（見積もりに理由を表示）。不要なら売る（基本装備は300G）。
- 一本釣り2本の効果（10分、濃い群れ）：手巻き2本で1本の約1.8倍、電動2本で約3倍（Lv1）。人による試遊で強すぎないか確認が要る。
- 沖の瀬は群れが大きいぶん、一本釣りの日の稼ぎが沿岸より大きくなりやすい。往復の燃料（中型で約60G/km×約9km）と時間とで釣り合うかは、人による試遊で確認が要る。
