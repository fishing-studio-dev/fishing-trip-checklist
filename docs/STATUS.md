## 起動方法

```
cd game
npm start            # http://localhost:8080/ を開く（Node 18以上、追加インストール不要）
# または: python3 -m http.server 8080 -d game
```

- ES Modules を使うため、`index.html` をファイルとして直接開く（file://）と動かない。必ずローカルサーバ経由で開く。
- `?dev=1` を付けると開発モード（海図に魚群を「開発表示」付きで表示、テスト用API）。通常プレイでは使わない。
- 検証：`npm test`（コア31件）、`npm run e2e`（ブラウザ通し試遊18項目）、`npm run lint`。

## 操作方法（PCキーボード／画面ボタン）

| 操作 | キー |
| --- | --- |
| 増速／減速（後進・停止・微速・半速・全速） | W・↑ ／ S・↓ |
| 舵（押している間だけ） | A・← ／ D・→ |
| 操業開始（停船中）／回収して終了 | Space |
| 流し直し（回収→流し始めの地点へ自動で戻り→再開） | R |
| 帰港・入港（移動補助。操船すると取り消し） | H |
| 海図に印 ／ 海図拡大 ／ 魚探表示 ／ 視点切替 | M ／ C ／ F ／ V |
| 時間の早さ ×1・×2・×4 ／ 一時停止 | 1・2・3 ／ P |

基本の流れ：港で予報を確認 → 出港 → 海図（瀬・根・駆け上がり）と魚探で群れの反応を探す → 潮上で停船 → Space で自動操業 → 反応が抜けたら R で流し直し、または移動 → H で帰港（着岸で自動的に一括水揚げ・精算・保存）→ 経験・資金で成長 → 装備購入 → 再出港。

## M0で実装した範囲

- 架空の海域（3km四方、港・北の瀬・西の根・東の駆け上がり等）と水深、潮流（潮回り・転流）、風、水温。
- マアジの群れ（1日3〜5群、日ごとに決定的に生成）。位置はゲーム時刻の連続関数、泳層は時刻で変わる、残量は獲った分だけ減る（その航海内）。
- 下向き魚探（探知範囲の密度から反応を算出、時間履歴表示、底の反応、タナ表示）。表示を閉じても記録は継続。
- 3D表示（three.js）：簡易モデルの船・海・港・釣り人。操船視点／作業視点の切替。電動リール購入で見た目が変わる。
- 自動操業（一本釣り・胴突き3本針）：魚探反応からの自動タナ取り、投入・誘い・追い食い待ち・回収・取り込み。船は潮と風で流れる（定点保持なし）。
- 漁獲 ≤ 候補（針の位置の魚密度）・処理能力（手返し）・群れ残量・魚倉残容量。掛かった時点で群れから予約。
- 漁法レベル（Lv1〜10）：餌付け・取り込み・投入・手巻き速度が向上。経験は主に漁獲尾数から、操業時間分は上限つき。
- 強化装備1種：電動リール DR-1（右舷竿受けの固定位置。外した手巻きリールは倉庫へ、付け替え可）。
- 帰港時に自動で一括水揚げ・売却・経費精算（資金不足分の経費は免除し、不漁でも再出港可能）。
- 操業日誌（操業ごとに自動記録：時刻・場所・水深・タナ・漁獲・魚探反応率・潮・レベル・装備・終了理由、不漁も記録）。
- セーブ：版付き・チェックサム・直前セーブのバックアップ・書き込み後の読み戻し確認・読めないデータの退避（削除しない）・書き出し／読み込み。出港時に航海開始を記録し、海上でページを閉じた航海は「中断」として報酬なしで整理。

## 残課題・既知の問題

- バランス（価格・経験曲線・群れの規模・潮の強さ）は仮設定。人による試遊で調整が必要。
- 1日目の早朝（05:00）は群れが高く浮いていて潮も速いことがあり、初回の漁獲が少なくなることがある（自動試遊の1航海目は2尾）。初心者体験として要確認。
- 群れの探索手掛かりは魚探と海図の地形のみ。海面の手掛かり（鳥山等）は未実装。
- 実機GPUのブラウザ、Firefox/Safari、スマホのタッチ操作は未検証（スマホ幅の表示崩れのみ確認）。
- `game/vendor/three/` に three.js（約2MB、未改変）を同梱。
- 日誌は保存容量のため最大500件（超えると古いものから削除）。M1で日誌を本格活用する際に扱いを再検討。
