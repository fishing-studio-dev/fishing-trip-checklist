### 試遊で見つけて直した問題（M3）

- 延縄の当たりが多すぎた（浸け15分でも48枚、群れの半分近く）→ 当たり率を2回下げ、針ごとの当たりの起点を一様にして、当たる針の割合が期待値に沿うようにした。

- 海図に、揚げ終わった針まで縄として描いていた → 海にある針だけを描く。

### 試遊で見つけて直した問題

- `hidden` 属性がCSSの `display` で上書きされ、透明なモーダルがクリックを遮っていた → `[hidden]{display:none!important}`。
- 1回の早送りが安全上限（4000ステップ）で黙って打ち切られ、テストが想定より短い時間しか進んでいなかった → 上限はUIのフレーム処理だけに適用、残りは持ち越し。
- 群れが小さく潮が速く、1回の流しが2〜4分で終わって漁獲が極端に少なかった → 群れの広がり・潮流を調整（DECISIONS参照）。
- 魚探のノイズで群れの縁の弱い反応が埋もれた → ノイズを疎にし、反応に粒立ちを付与。
- 作業視点のカメラが操舵室に遮られた → 釣り人の背後上方へ移動。
- 着岸後に精算ボタンを押す前に閉じると漁獲が失われる → 着岸時に自動精算・保存。
- スマホ幅で状態表示と操船ボタンが重なった → モバイル配置を調整。

### 未確認事項

- 人による実際の試遊（操作感・テンポ・難易度・バランス）。自動試遊は群れ位置を読み取る「船長」で行っており、魚探だけで探す難しさは未評価。
- 実GPUを持つPCブラウザでの描画性能、Firefox・Safari、Windows/macOSでの表示。
- スマホ・タブレット実機でのタッチ操作（舵の長押し等）。
- 長時間プレイ・多数航海でのセーブ容量（日誌は最大500件で古いものから削除）。
- ブラウザのストレージ制限・プライベートモードでの挙動（保存不可時の表示はコード上のみ確認）。
