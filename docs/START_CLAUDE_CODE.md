# Claude Code｜最初の指示文

下のコードブロックの中身を、資料を置いたプロジェクトを開いたClaude Codeへ貼り付けてください。既存プロジェクトがある場合は、その作業フォルダを使い、資料を理由に既存ファイルを一括上書きしないでください。

## 最初に貼る指示文

```text
このフォルダの資料を引き継いで、漁師ゲームの開発を進めてください。
まず既存のAGENTS.md・CLAUDE.mdなどの適用ルールを確認し、FISHING_GAME_HANDOVER.mdを読んでください。既存コード、素材、セーブ、起動方法があれば実物を確認し、作り直しを前提にしないでください。

最も重要な最新方針は次のとおりです。

・魚群探索・ポイント選定は手動。その後の投入、基本タナ調整、誘い、合わせ、回収は最初から自動。
・曳縄を採用する場合も、航路・範囲の選択後は通常航行と漁具作業を自動にし、継続的な手動操船を必須にしない。変更・中止は随時指示できる。
・同じ漁を繰り返すと習熟し、作業効率と漁獲量が上がる。
・漁師仲間の情報、自分の操業記録、今日の海況と現場の魚探から、狙う魚・漁法・漁場を判断できる。
・漁のリアル感を重視し、収支と船選びはシンプルなゲーム設計にする。
・一隻の船を育てる。新艇・中古船、固定取付位置への装備の組み合わせは残す。
・細かな手動釣り、QTE、複雑な故障・整備・経営へ戻さない。

最初は引き継ぎ書のM0を実装してください。
出港→魚群探索→ポイント決定→自動操業→帰港・売却→漁法レベルと装備の成長→再出港を、実際に操作できる形にします。
M0の次はM1で仲間情報・自動日誌・海況による選択を実装します。M0だけでゲーム構想全体が完成したとは扱わないでください。

開発エンジンと初期対応端末はまだ確定していません。まず利用できる環境を確認し、採用する構成と理由、仮定を短く示してください。既存の適切な環境があれば活用してください。軽微な選択は自律的に進め、設計の根本に影響して判断できない事項だけを一問ずつ確認してください。

準備・計画だけで終えず、環境と権限の範囲内で実装、必要な検証、通し試遊まで進めてください。起動や試遊ができない場合は、その制約と実施できた検証を明示してください。

魚群・魚探・漁獲を同じ状態から計算し、視点切替や魚探の開閉で魚を再抽選しないでください。レベルが高くても魚がいない場所では獲れず、よいポイントでは成長の効果が分かるようにしてください。

日誌、経験値、資金、船、装備を保存・復元できるようにし、二重報酬やデータ消失を防いでください。既存の成果物とセーブを保護してください。

作業後は、起動方法、操作方法、実装した範囲、実施した検証、未確認事項、残課題、次の作業を報告してください。作業記録と採用した仕様をプロジェクト内に残してください。
```
