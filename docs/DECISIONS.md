# 決定事項と開発上の選択

区分：**ユーザー決定**（引き継ぎ書の[確定]/[最新方針]）／**開発選択**（Claude Codeが理由を付けて選んだ可逆な事項）／**仮設定**（試作の数値）

## ユーザー決定（維持）

引き継ぎ書 §2.1 の D01〜D12 をそのまま維持する。特に：探索・ポイント選定は手動、反復作業は最初から自動（D09）、同じ漁の反復で習熟（D10）、情報で漁を選ぶ（D11）、経営はシンプル（D08）、一隻を育てる（D02）。手動釣り・QTE・故障整備・複雑な経営は入れない。

## 仮設定（`game/src/core/data.js` に集約）

- 価格(G/kg)：小アジ400・中アジ700・大アジ1000。開始資金5,000G、電動リール15,000G。
- 魚倉120kg。速力 微速2.0／半速4.5／全速8.0 m/s。
- 習熟（Lv1→Lv10）：餌付け15→5秒、取り込み8→2.5秒/尾、投入1.2→1.7m/秒、手巻き0.7→1.1m/秒。電動2.6m/秒・対応150m（手巻き80m）。
- 経験曲線：Lv2=30, Lv3=80, Lv4=150 … Lv10=1050。
- 群れ：1日3〜5群、各300〜900尾、水平σ35〜65m、鉛直σ2.5〜4m。当たり上限0.1回/秒/針、半飽和密度0.004尾/m³、追い食い待ち10秒。
- 潮流の最大：大潮0.34m/s〜長潮0.09m/s。風による流され率2.5%。
- マアジの行動（本作設定）：日中は底近く、早朝は底から高く浮く、潮が動くと活性が上がる。実在魚の数値を転用したものではない。
- サワラ（本作設定）：サゴシ1.0kg/350G・サワラ2.5kg/600G・大サワラ4.5kg/800G（1kgあたり）。群れは20〜55尾、水平σ70〜120m。表層から3〜8m、朝は浅め。水温18.8℃以上で回遊。当たり上限0.05回/秒/仕掛け、半飽和密度0.0001尾/m³。
- 曳縄の習熟（Lv1→Lv10）：投入60→12秒、やり取り30→10秒、手繰り0.8→1.6m/秒、取り込み15→5秒。曳縄具9,000G（仕掛け2本、潜行板3m・7m、曳航2.6m/秒）。
- 潮回りの暦：大潮4日・中潮6日・小潮系5日の15日周期（日付に+10してから参照）。
- 速力の段（m/s）：小型 後進-1.5・極微速0.8・微速2.0・半速4.5・全速8.0／中型 後進-1.8・極微速0.9・微速2.2・半速5.0・全速10.0。
- 中型漁船：魚倉320kg、燃料60G/km（小型40G/km）、風で流され率1.8%（小型2.5%）、旋回はやや遅い。下取り：小型15,000G・中型55,000G。
- 売り物：中型 新艇110,000G／中古A 65,000G（ES-1・手巻き2本付き）／中古B 85,000G（ES-2・電動・TR-1付き）、小型 新艇40,000G／中古22,000G。
- 二周波魚探 ES-2：32,000G、ビーム28°（ES-1は44°）、表示0.25m、120mまで、雑音少なめ・感度高め。
- 曳縄具 TR-2：26,000G、仕掛け4本（潜行板3・7・2・5m）、外側2本はアウトリガーで横10m。
- 装備の売値：購入価格の半額、基本装備は300G。
