# 決定事項と開発上の選択

区分：**ユーザー決定**（引き継ぎ書の[確定]/[最新方針]）／**開発選択**（Claude Codeが理由を付けて選んだ可逆な事項）／**仮設定**（試作の数値）

## ユーザー決定（維持）

引き継ぎ書 §2.1 の D01〜D12 をそのまま維持する。特に：探索・ポイント選定は手動、反復作業は最初から自動（D09）、同じ漁の反復で習熟（D10）、情報で漁を選ぶ（D11）、経営はシンプル（D08）、一隻を育てる（D02）。手動釣り・QTE・故障整備・複雑な経営は入れない。

## 開発選択（M3の最初の区切り、2026-11-23）

引き継ぎ書のM3は「甲板自由移動＋ショートカット、乗組員と機械の動作、追加漁法、魚種・海域・季節など」で、完成条件の定めがない。そこで、最初の区切りを次のとおり決めて進めた（可逆な開発選択）。

| ID | 選択 | 理由・仮定 |
| --- | --- | --- |
| C55 | M3の最初の区切りは、延縄（マダイ）、甲板の自由移動と持ち場ショートカット、釣り人と機械の動き。追加の海域・季節の移り変わり・乗組員は次の区切りに回す | 判断の種類が増える漁法（置いておき、揚げる時機を決める）と、船への愛着（歩いて見て回る）を先に入れる。乗組員は「乗組員を買わないと自動化できない」にならない形の検討が要るため後にした。 |
| C56 | 3つ目の漁法は **延縄**、対象は **マダイ**（本作設定：深めの平場・駆け上がりの底に薄く広く散る） | 引き継ぎ書§6.3の候補。一本釣り（群れの上で止まる）・曳縄（走りながら）と違い、置いて待つ漁で、「どこに張るか」と「いつ揚げるか」の判断が出る。薄く散る魚は一本釣りでは効率が悪く、縄で広く探る意味がある。 |
| C57 | 延縄の釣果は、針1本ごとに、置いた場所の密度・活性・餌の残りから10ゲーム秒ごとに当たりを積算する。当たりの時点で群れから1尾を予約し、魚倉に入らないなら当たりにしない | §6.3「設置位置を保存し、時間経過中に魚が通過する機会を評価する。時間が過ぎれば場所に関係なく定量の魚が生成される方式にはしない」。10秒ごとはゲーム時間の歩数で決まるため、描画頻度や早送りで結果が変わらない（A07）。 |
